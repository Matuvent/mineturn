# 首领状态机设计：监守者、末影龙、凋灵

本文汇总三名生物在「我的回合」（MineTurn）中的**设计提案**，供后续对话和实现参考。除特别说明外，状态、技能、数值均尚未实现，也不是原版行为的精确复刻。数值是第一轮平衡起点，需经 GameTest 与实际游玩调整。

## 共通规则

- 所有预告、持续时间、冷却和蓄力使用战斗 AV；玩家思考时不推进 AV。预告必须在战斗界面和世界中清楚显示目标、区域及结算时机。
- 首领行动遵守主要行动、移动预算、碰撞、视线、阵营和战场边界。延迟结算时重新检查施术者、目标、战斗归属及相关射程；失败不返还已支付成本，除非技能另行定义。
- 范围效果仅作用于同场合法参与者。死亡、离场、数据包重载及战斗关闭时清理预告、定时任务、视觉状态和临时区域。
- 阶段切换优先于普通回合决策，但不应无成本插队攻击。一个预告对应一次明确的结算，避免同一目标重复受击。
- 现有旧 `states` 状态机仅支持 `approach`、`weighted_action`、`wait` 和 `in_reach`、`out_of_reach`。以下复杂首领应使用 `mcfunction` 管理决策，必要的技能、状态及实体特性由 Java 扩展。

## 1. 监守者（Warden）：感知与锁定

**体验目标：**玩家能看出监守者正在搜寻、锁定或蓄力，并通过移动和站位改变风险。不是每回合机械选择最近敌人。

### 状态与转移

| 状态 | 进入条件 | 本状态行为 | 离开条件 |
| --- | --- | --- | --- |
| 搜寻 | 入战后无明确目标；线索丢失 | 等待并记录有效线索 | 感知到同场敌人 → 警觉 |
| 警觉 | 出现线索但尚未锁定 | 提升线索来源的关注度，展示锁定过程 | 达到锁定门槛 → 追击；线索消失 → 搜寻 |
| 追击 | 已锁定目标 | 按现有寻路和移动预算接近目标；移动完成后不追加攻击 | 进入近战范围 → 近战；音波条件满足 → 音波蓄力 |
| 近战 | 目标在近战范围且攻击合法 | 消耗主要行动近战 | 目标脱离 → 追击 |
| 音波蓄力 | 目标在音波范围、技能就绪 | 消耗主要行动，预约 AV 结算；蓄力期间跳过普通 AI | 蓄力完成 → 音波结算；目标离场等导致取消 → 追击 |
| 音波结算 | 预约到期 | 重新检查目标并结算；落空也进入冷却 | 追击或搜寻 |

**目标策略：**每只监守者维护独立的目标线索与愤怒值。受伤来源优先，其次是持续制造线索的敌人；同等愤怒时选择更近者。新目标须明显超过当前目标才切换，避免多人战斗中频繁转向。具体声音、嗅探、愤怒增长与衰减规则尚待实现时细化。

**技能约束：**音波的射程、遮挡规则、蓄力 AV、伤害和冷却应放在技能定义或配置中，不能仅靠现有 `in_reach` 转移表达。预告必须指出被锁定者及预计结算时机。

**最小实现：**先实现目标记忆、警觉预告、追击、近战与一次可取消的音波蓄力；再加入更复杂的声音与嗅探来源。

## 2. 末影龙：争夺战场控制权

**体验目标：**龙在空中施压，玩家处理水晶与危险区域，抓住降落窗口攻击头部。它不沿用原版战斗节奏。

### 阶段

| 阶段 | 进入条件 | 行为与玩家机会 |
| --- | --- | --- |
| 空域压制 | 开战、重新起飞 | 盘旋、预告俯冲或吐息；玩家可处理水晶、重新站位 |
| 降落交锋 | 俯冲结束或水晶被击破造成落地机会 | 爪击、扫尾、翼击；头部成为稳定输出窗口 |
| 裂隙狂暴 | 生命低于 35% | 组合两种招式，增加裂隙压力；仍保留预告与招式后的硬直 |

### 回合循环

`盘旋 → 俯冲预告 → 俯冲 → 降落 → 近身招式或吐息预告 → 硬直 → 起飞 → 盘旋`。

- 俯冲预告显示起点至落点的带状危险区，经过一次玩家行动机会后结算。路线受阻也会结束俯冲并进入降落处理。
- 降落阶段按玩家站位选择爪击、身后扇形扫尾或两侧翼击。扫尾可强制位移；翼击后可起飞。
- 吐息预告显示地面圆区，结算后生成持续 **300 AV** 的龙息裂隙，每 **100 AV** 对区域内合法目标结算一次伤害。裂隙数量须设上限，避免永久占满场地。
- 狂暴阶段的「末影震荡」依次标记两片互不重叠区域，分次结算；玩家需要为第二次躲避保留移动距离。
- 俯冲受阻或降落时水晶被摧毁，龙可进入额外硬直，形成主动创造的反击窗口。

### 水晶

每颗存活水晶为龙提供少量恢复，并缩短重新起飞的间隔。击破水晶立即打断当前恢复，延长下一次降落。水晶**不让龙完全免伤**，玩家可以选择先打水晶或先攻击龙。水晶数量、恢复量和延长时长留待平衡；需明确其参战归属、受击方式与胜负判定。

### 技术边界与首版

普通战场目前是水平半径 16 格、上下 6 格；龙战需专用区域配置。多部件命中、头部破绽、水晶归属、飞行路径和视觉预告需要专用 Java 控制器；龙身各部件不作为独立参战者。首版只做 `盘旋 → 预告俯冲 → 降落两回合 → 起飞`，加水晶和一种龙息区域；确认循环有趣后再加入扫尾、翼击及狂暴组合。

## 3. 凋灵：不断变化的安全区

**体验目标：**玩家在分散躲弹、靠近输出、清除印记和打断蓄力之间分配行动。与末影龙的降落输出窗口形成不同节奏。

### 凋零印记

部分技能施加持续 **300 AV** 的凋零印记。被另一项指定凋灵技能命中时，引爆印记、造成额外伤害并清除。每名玩家最多一层；可通过治疗或指定净化动作提前解除。印记本身不应承担主要伤害，重点是制造下一次命中的威胁。具体治疗与净化的触发条件需在实现前固定，避免所有治疗无成本顺带净化。

### 阶段与状态

| 状态或阶段 | 进入条件 | 行为与转移 |
| --- | --- | --- |
| 浮空游走 | 开战及普通循环，生命高于 50% | 飞行调整位置；选择交错骷髅弹预告或汇聚蓄力 |
| 骷髅弹预告 | 已选择两个落点 | 经过一次玩家行动机会后结算弹幕，返回浮空游走 |
| 汇聚蓄力 | 能量达到门槛 | 停止移动并标出爆发范围；完成 → 凋零爆发；被打断 → 较长虚弱窗口 |
| 凋零爆发 | 蓄力完成 | 伤害范围内目标并引爆印记，随后进入虚弱窗口 |
| 虚弱窗口 | 爆发或打断后 | 暂时无法攻击，承受更高伤害；结束后返回对应生命阶段 |
| 护甲阶段 | 生命低于 50% | 飞得更低，削弱远程伤害，改为近身压迫与蓄力循环 |
| 绝境反击 | 生命低于 20% | 爆发后立即选择下一次骷髅弹落点，仍给予完整预告 |

### 招式

- **交错骷髅弹：**标记两名玩家当前位置，下次凋灵行动结算两个小范围爆炸；标记后不持续追踪。两处范围重叠时同一目标仅受一次爆炸伤害。
- **腐化地带：**骷髅弹落点留下持续 **200 AV** 的危险区域；同场最多保留三处，新区域生成时移除最旧的一处。
- **灵魂牵引：**预告一名有印记的玩家，结算时将其向凋灵拉近一小段，准备后续近身冲击。调用现有强制位移碰撞检查，不穿墙，也不能把玩家送进无路可走的位置。
- **凋零爆发：**预告自身周围的范围；场上印记越多，范围越大，但设置上限。蓄力期间若玩家造成足够伤害，取消爆发并延长虚弱窗口。打断门槛随参战人数调整。

**目标策略：**骷髅弹优先选择远处或聚集的目标，护甲阶段优先压迫近处目标。连续被锁定者获得短暂目标选择保护，避免单人反复承受全部预告。

**最小实现：**交错骷髅弹、腐化地带、半血护甲阶段与可打断爆发。印记、灵魂牵引和绝境反击在核心循环稳定后加入。

## 实现顺序与验收重点

1. 先实现可复用的「AV 预告 → 扣费 → 延迟结算 → 取消清理」基础能力，保证玩家有完整反应机会。
2. 为各首领分别维护状态、阶段、冷却、目标和临时区域；不要复用旧状态机的两种距离条件承载所有逻辑。
3. GameTest 至少覆盖预告时 AV 不流逝、结算重检、死亡或离场清理、同场过滤、多人目标切换、重复命中保护、阶段边界和冷却。
4. 实际客户端检查预告可读性、危险区与实体动画是否一致，以及玩家能否在正常移动预算内躲避。数据数值经游玩调整后再视为定稿。
