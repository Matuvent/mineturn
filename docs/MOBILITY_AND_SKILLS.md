# 飞行、水下移动与特殊技能接口

## 生物移动方式

生物 JSON 和 AI 模板支持 `movement_mode`，默认 `ground`。这是生物 AI 配置；玩家根据脚部是否处于水中自动切换地面和游泳移动，不开放自由飞行。

```json
{
  "entity": "minecraft:vex",
  "template": "mineturn:flying_melee"
}
```

内置模板 `mineturn:flying_melee`、`mineturn:swimming_melee` 继承普通近战模板，只改变移动方式。也可以在自己的函数 AI 配置中写 `"movement_mode":"flying"` 或 `"movement_mode":"swimming"`。

- `ground`：陆地保持上一格台阶、落下和摔伤规则；脚部进入水中后自动按三维游泳追击，出水回到地面模式。
- `flying`：允许三维直线移动，不需要地面支撑，移动本身不产生摔伤；不能穿墙或进入液体。
- `phasing`：允许穿过方块及液体的三维移动，内置恼鬼使用此模式；仍检查已加载区块、世界边界、建筑高度、X/Y/Z 曼哈顿预算和周身控制。攻击仍需视线与射程，穿墙不等于隔墙命中。支持同步/异步移动、追击和三维寻路，不会主动加载区块。
- `climbing`：每一步需要地面或邻近墙面支撑，可沿墙上下移动；不穿墙，按三维曼哈顿距离扣费。内置蜘蛛采用此模式。
- `swimming`：允许三维直线移动，整个碰撞箱及经过的路径必须位于水中；不能越过水面、离水、穿墙或进入岩浆。当前不支持水陆两栖切换。

移动预算统一采用曼哈顿距离：陆地为 |ΔX| + |ΔZ|，飞行/游泳为 |ΔX| + |ΔY| + |ΔZ|。例如横移 3 格并上浮 4 格消耗 7 格；陆地横纵各移动 1 格消耗 2 格。陆地台阶和下落仍不额外扣除垂直移动距离，摔伤规则不变。每回合距离仍由现有移动速度属性计算，疾跑翻倍剩余距离。空间路径按完整碰撞箱检查，尊重世界边界、高度范围和已加载区块；不为移动加载新区块。

`toward_target` 对飞行/水下生物会考虑高度差。新增函数命令：

```mcfunction
mineturn ai move3d 0 2 0
mineturn ai move3d 1 -1 2
```

参数依次是相对位移 dx、dy、dz。原来的 `move dx dz` 仍可用。地面模式拒绝非零垂直位移；仍通过地形自动上台阶。

周身范围按三维碰撞箱距离判断。可以进入并靠近敌人，但已受控制时再次移动必须先撤退；不能靠垂直升空绕过。路径受阻时可以走到合法的中途位置，只扣除实际距离。旧同步函数移动和显式位移沿直线；状态机及 move_async toward_target 在陆地、飞行和水下均共用追击绕障。玩家陆地点选遇阻时会在剩余移动距离内搜索绕行路线，按实际绕行长度扣距；预览显示服务端确认的路径点。搜索最多展开 512 个节点，不加载新区块，复杂地形可能找不到路线。绕行仍检查整条路径的碰撞、台阶、摔伤和周身范围。

玩家 GUI 陆地和水下移动由服务器沿路线逐步推进，客户端插值显示位置和步行动画；上台阶先抬升再前进，下落到达落点才结算摔伤。移动期间禁止再次移动、攻击、疾跑、撤退、逃跑和结束行动，不推进 AV；增援扫描延后到移动结束。路线距离在开始时一次扣除，途中出现新障碍则停在最近已通过的采样点，不退还已预留距离；失去支撑时按原有自动落地规则处理。退出或死亡会清除移动状态。旧函数 AI 移动指令和备用移动命令仍即时结算；函数 AI 可选用异步指令，见 ASYNC_AI.md；下落目前为匀速路线动画，尚未模拟重力加速。

## 玩家水下操作

水下点选沿三维路径逐步移动，直线受阻时在剩余预算内搜索完整绕行路线，预览与执行使用相同的水体、支撑及碰撞检查。每一步都会重新检查环境，途中水体消失、出现障碍或岩浆会中止路线；仍在水中则停在当前深度，失去水体与支撑则按自动落地规则处理。下潜不累计摔落距离，移动动画不推进氧气、药水、燃烧或 AV 时钟。入水及上岸也使用同一套动画；已支持绕开水下障碍，找不到预算内完整路线时拒绝点选移动。

点击“移动”后，鼠标在当前高度平面选择方块中心（X/Z 坐标为方块坐标 + 0.5）；按 **E 上浮一格、Q 下潜一格** 调整目标高度，单击确认，右键取消。按三轴位移绝对值之和扣除移动距离，周身范围仍要求先撤退。水中不会被自动拉到水底；允许停在水面及移动到有支撑的岸边，不能上浮到无水、无支撑的空中。陆地点选可以选中水面；仍要求整条路径合法，直线受阻时尝试预算内绕行。

## 数据包技能示例

动作 JSON 新增 `parameters` 对象，用于传给效果执行器；最大序列化长度 8192。内置 `mineturn:burst` 演示即时或预付 AV 的范围伤害：

```json
{
  "name": "蓄力炎爆",
  "effect": "mineturn:burst",
  "amount": 6,
  "range": 12,
  "cooldown_av": 200,
  "parameters": {"radius": 3, "delay_av": 50}
}
```

AI 通过 `mineturn ai use my_pack:flare` 施放，照常检查行动、目标、距离、视线、物品消耗与冷却。

施放时消耗主要行动和物品，冷却从施放 AV 开始。50 AV 后在目标**当时的位置**结算半径 3 格的伤害，只影响同场敌人并检查从中心到敌人的视线。`delay_av: 0` 是即时结算。该效果不产生火球实体、不点燃或破坏地形，也没有新增蓄力动画。

延迟以战斗时间轴计算，玩家现实中等待不会让技能提前触发。结算不会再扣一次主要行动，也不授予新行动。目标或施法者死亡、离场、换维度，或者战斗结束/重载时，尚未结算的技能取消，已付出的行动不会退还。

## 附属模组 Java 接口

通过已有的 `CombatEffects.register` 注册自定义效果，在模组初始化期间、数据包首次加载前完成。JSON 使用该效果的资源 ID，mcfunction 决定何时调用它。示例：

```java
CombatEffects.register(ResourceLocation.parse("my_compat:boss_shockwave"), new CombatEffects.Effect() {
    @Override
    public void validateDefinition(CombatData.Action action) {
        CombatEffects.parameter(action, "radius", 4, 0.1, 16);
    }

    @Override
    public String validate(CombatEffects.Context context) {
        // 可检查具体 Boss 类型、阶段、魔力等；失败返回提示，成功返回 null。
        // 此处必须只读，可能被 GUI 预览和 AI query ready 多次调用。
        return null;
    }

    @Override
    public void execute(CombatEffects.Context context) {
        context.battle().after(30, impact -> {
            double radius = CombatEffects.parameter(impact.action(), "radius", 4, 0.1, 16);
            for (var enemy : impact.battle().enemies()) {
                if (enemy.distanceToSqr(impact.source()) <= radius * radius
                        && impact.source().hasLineOfSight(enemy)) {
                    impact.battle().hurt(enemy, (float) impact.action().amount());
                }
            }
        });
    }
});
```

接口职责：

- `validateDefinition(action)`：加载/重载时验证效果特有参数，非法配置抛出 `IllegalArgumentException`，阻止发布新定义。
- `validate(context)`：施放前只读检查；不能安排延迟技能或造成伤害。
- `execute(context)`：服务端线程执行一次，此时主要行动与冷却已提交。即使执行器异常，行动和冷却也不回滚，物品消耗仍结算。
- `context.action().parameters()`：返回参数副本，避免适配代码意外改写已加载定义。
- `context.battle().enemies()`：返回当前同场存活敌人的列表副本。
- `context.battle().hurt(enemy, amount)`：执行期授权伤害，检查同场、敌对、存活和维度；数值须有限且在 0–1000 内。范围/视线由技能实现决定。
- `context.battle().after(delayAv, continuation)`：仅限 `execute` 或正在执行的托管延迟回调，延迟 0.01–100000 AV。使用全新的执行上下文和最新战斗时间，物品是施放时的副本。不可把旧上下文保存后用服务器 tick 或异步线程调用。

技能定时器与函数定时器共用每场最多 128 个待执行任务、一次时间推进最多 128 次触发的限制。施法者离场时清理所属任务；任务异常记录日志并继续推进时间轴。该接口只保证 MineTurn 提供的调用范围，Java 适配代码本身仍是受信任代码。

`on_action_resolved` 对延迟技能表示**施放完成**，不是延迟伤害命中；需要命中阶段状态时由 Java continuation 自行更新计分板或自己的状态。原版 `mineturn ai schedule` 仍是只读行动回调，不能因此免费攻击。

阶段切换、概率选择、蓄力决策可以继续写在 mcfunction 中。调用第三方 Boss 内部技能、特殊投射物或模型动画，需要该模组的 Java 适配；此接口不会自动接管所有 Boss 自己的 tick 逻辑，也不代表已经适配灾变或末影龙。长期存在的原版投射物应另行适配，不能假定离开当前执行上下文后仍有伤害授权。

## 可直接安装的示例

`examples/spatial-boss/` 展示恼鬼飞行近战、守卫者水下近战、烈焰人飞行与蓄力炎爆。守卫者需要在足够宽深的水体中测试。

运行 `gradlew.bat spatialBossExamplePack` 生成 `build/examples/mineturn-spatial-boss-example.zip`，放入世界 `datapacks` 并启用、`/reload`。该包可独立使用；与其他包同时注册同一实体时，使用前述匹配优先级或覆盖原文件解决冲突。

入战及增援时将参与者水平位置对齐所在方块中心，水下同时对齐脚部整数高度。若对齐路径碰撞或越过世界边界，保留安全原位；空中入战保留原有下落距离并继续结算落地。点击移动直接交由服务端校验，不再要求鼠标点击前已收到预览包。

## 状态机陆地追击

`ground` 生物的 `approach` 状态（如内置僵尸）沿服务端路线逐步移动。直线路径受阻时，先搜索目标附近的落点；正面不可达时再尝试两侧及背侧。寻路最多前瞻本回合预算加 12 格（总长上限 40），每个候选最多展开 512 节点，不加载新区块；本回合只执行预算内且有支撑的路线前段。复杂迷宫可能找不到路线，不能保证全局最短。

移动期间不会重复执行状态机或推进 AV；到达或被新增障碍中止后结束本次追击回合。保持原有追击/攻击分离规则：下一次轮到生物时才检查是否转入攻击状态。途中落地按原有摔伤规则结算；死亡、退出或战斗关闭会清理移动状态。函数 AI 的移动指令仍保持同步执行，不会隐式暂停 mcfunction；异步移动与完成回调现已通过独立指令提供，见 ASYNC_AI.md。

## 状态机三维移动动画

状态机 `approach` 的 `flying`、`swimming` 以及水中的 `ground` 生物现在也沿服务端采样路径逐步移动。飞行保持终点高度，下降不累计摔落距离；严格游泳模式继续要求整个碰撞箱处于水中，水中 ground 模式允许水面和有支撑的岸边。每个采样步骤重新检查碰撞和流体边界，途中出现障碍或水体变化则停止；移动结束后才切换回合，期间不推进 AV。

三维追击已支持有界绕障，保留各移动模式的流体限制。此功能针对 states 状态机；使用 mcfunction 的内置 flying_melee/swimming_melee 模板仍保持同步移动，可改用 animated_melee 模板或 move_async 指令接入动画，见 ASYNC_AI.md。客户端具体物种的翅膀/游泳模型动画需分别实测，本轮实现的是路径位移与回合衔接。

## 三维寻路限制

三维搜索采用六邻接节点，节点之间及终点连接都经过扫掠碰撞、流体和周身范围检查，最多展开 512 节点/候选，不加载新区块。怪物追击允许前瞻预算加 12 格、最长 40 格，再截取本回合可负担的前段；玩家水下点选只接受预算内能完整到达指定位置的路线。该有界搜索不保证复杂迷宫一定有解或全局最短，实际服务器负载与画面仍需联机实测。

距离规则适用于玩家点选、备用移动命令、状态机和函数 AI、路径预览、绕障搜索及路线前段截取。绕行按每段曼哈顿距离累加，不能只计算起终点差。角色仍可沿斜线平滑移动；攻击射程、周身范围、远程判定距离和视觉插值不使用此预算度量。


## 公共传送接口

玩家/生物技能可使用 BattleAccess.previewTeleport 与 teleportTo；数据包可以直接注册 mineturn:teleport_offset 动作。费用、上下文约束、骑乘规则和可安装示例见 [TELEPORT_API.md](TELEPORT_API.md)。
