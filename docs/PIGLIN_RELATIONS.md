# 猪灵参战与敌我关系

普通成年猪灵不再仅因实现 Enemy 接口就无条件加入附近战斗。它与场内参与者存在敌对关系时才自动加入：已有攻击/愤怒目标、实际交战关系，或玩家没有提供原版猪灵中立效果的装备。

装备判断调用原版 `PiglinAi.isWearingGold`，沿用 NeoForge 的 `ItemStack.makesPiglinsNeutral` 扩展能力，不自行列一张金装备表。数据包 participation=never 仍禁止参战；participation=hostile 可以显式取消成年猪灵的装备中立限制。

- 原版 ATTACK_TARGET 优先；没有有效攻击目标时读取 ANGRY_AT，保存为战斗中的优先目标。
- 对已有攻击/愤怒目标和实际交战对象，金装备不能抹去敌对关系。
- 场内穿中立装备的其他玩家不会仅因旁人激怒猪灵就被一起视作敌人。
- 猪灵已有围猎疣猪兽等生物目标时，保留该目标及双方敌对关系。
- 幼年猪灵不因玩家没穿金装备自动参战；实际发起攻击或被直接攻击仍可建立战斗。
- 猪灵蛮兵保持主动敌对，不受金装备保护。僵尸猪灵继续使用已有的独立群体愤怒规则。

本组不新增交易、分心、金块/箱子交互、围猎目标生成或群体告警算法；这些原版行为在战斗外继续由原版负责。本组只继承原版已经形成的目标，不推进 Brain 的整套 AI 或记忆计时。已有战斗锁禁止换装。

自动化覆盖金装备中立/无装备招募、蛮兵区别、愤怒目标与金装备旁观者、实际伤害挑衅、围猎目标、幼年过滤和外部攻击加入。客户端多人目标显示及真实下界生态仍待实测。
