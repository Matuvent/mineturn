# 全生物机制盘点与回合制规划

> 基准：Minecraft Java 1.21.1 / 当前 MineTurn 源码，2026-10-02。
> 2026-10-02 最终范围调整：原版维持简洁，优先通用战斗能力和物品使用；复杂机制重点留给完成核心模组后的暮色森林、灾变附属模组。本文记录需求定案，不代表新需求已实现。

## 1. 范围、统计和读法

本次从项目使用的 `EntityType` 注册表出发，沿 Java 类继承关系筛选 `Mob` 子类，得到 **82 个原版生物类型**。包含末影龙、凋灵、监守者，以及只能通过命令出现的巨人、幻术师、僵尸马等；幼年、大小、颜色、职业、装备和狼的外观变种不重复计数。

正式内置生物 JSON 中已登记 **40 种**，尚未登记 **42 种**。示例/测试数据包里的额外映射不算正式适配；外部数据包也可能覆盖下文行为。

> **这 40 种由测试核对**：`test/CoverageMatrixGameTests.java` 从服务端实际解析结果读取登记表，确认原版登记为 40、外加模组自加的 1 个实体（`mineturn:shulker_bullet_unit`），合计 41。文档数字一旦漂移，测试会失败。

### 四个状态词的含义（不要混用）

| 状态 | 判据 | 代码依据 |
| --- | --- | --- |
| **已注册** | 存在内置生物 JSON | `data/mineturn/mineturn/mobs/*.json` |
| **可用** | 该 JSON 的 `participation` 不为 `never`，且不在资源排除标签内 | `BattleParticipation.allowed` |
| **禁用** | 无登记，或 `participation: never`，或属于 `mineturn:non_combatants` 且 `participation: auto` | 同上 |
| **待实测** | 服务端已通过验证，但**画面/手感/联机**需真机确认 | [客户端手测表](CLIENT_ACCEPTANCE.md) |

**"已注册"不等于"机制完整"**，也不等于"可用"。当前实测：登记原版 40 种，参与模式为 `{auto=38, neutral=3}`（含模组实体），资源排除标签列有 38 种。

- **原版机制**：本版本已有、与行为/战斗/环境互动相关的物种特征概述；不是完整的刷怪条件、掉落表或数值百科。
- **当前 MineTurn**：根据当前生物 JSON、mcfunction、Java 效果及战斗管理代码盘点。已登记不等于特殊机制完整。
- **最终范围 / 状态**：用户认可的现有机制标为"当前范围已完成"；新规则明确标为待实现；不参战类型不再计为欠缺 AI。登记数量与范围完成度是两种统计。
- **未登记**：没有正式内置回合制 AI；不是说该生物在整个游戏中失去原版机制。它们不在受支持的战斗范围内时仍运行原版行为。

当前会冻结入战生物的原版 tick/AI。因此，“这个类原来会做”不代表“入战后已经能做”。部分原版伤害免疫、受击回调和属性可能仍生效，但未经专门适配和验证的分支不列为完成。

不包含 1.21.1 之后新增的生物，不将基岩版专属行为当作 Java 版机制。玩家不是这 82 个 Mob 类型之一；盔甲架、龙的部件、箭、火球、潜影弹、药水云、末影水晶等也不作为独立生物重复计数，相关对象的战斗交互仍需规划。

## 2. 当前基础能力，以及仍缺少的公共机制

已有：AV 队列、主要/次要行动次数、重复移动预算、曼哈顿移动距离、疾跑/撤退/逃跑、周身控制、地面/飞行/游泳/攀墙/穿墙路径、目标选择、状态 AV 计时、原版属性/部分装备效果、托管延迟技能、条件行动、基础友军关系和分裂接战。普通攻击不击退；技能有显式强制位移接口。玩家举盾消耗主要行动，只格挡一次符合原版规则的攻击，到下次自己的行动开始时过期。

后续公共能力服务于已确认需求，不再要求为全部原版生物建立复杂机制：

- **物品使用优先**：原版攻击属性、食物组件、药水效果、附魔、消耗/容器、耐久与冷却保持统一；数据包可覆盖、新增，附属模组使用相同入口。
- **AV 延迟动作**：装填、充能、冷却、召唤与持续对象共享扣费、到期重检和死亡/离场/重载清理；幻翼及 Boss 的预告需留实际应对机会。
- **阵营/参战过滤**：支持不参战资源生物、僵尸猪灵群体愤怒、僵尸疣猪兽独立阵营和友军协战；外部数据包可明确覆盖内置策略。
- **位移与骑乘**：风弹、瞬移、坐骑复用移动验证。普通攻击继续无击退；仅显式技能强制位移。
- **场上单位**：召唤物、追踪弹、持续区域统一登记、推进和清理，不凭新增实体获得无限免费行动。

不制作恶魂火球反弹、潜影贝复制、猪灵分心、末影人注视、蠹虫藏身、幻翼猫驱退、旋风人红石交互和挖掘疲劳。爆炸地形效果需明确配置并尊重保护规则；玩家放置、破坏及工作方块操作限制不变。

## 4. 已实现但仍需重新设计的重点

### 4.1 幻翼：不能以反复升降代替机制

第五组之前是普通飞行近战的扩展：高度够时俯冲，低空时爬升，贴身时先撤退。它证明了动画、碰撞和资源结算能工作，但玩家主要仍在交换伤害，没有真正的空袭应对过程。保留旧代码作为可复用执行能力；正式 AI 已按下方流程替换。

已采用的状态方向（具体时长和成本待调试）：

1. **盘旋侦察**：挑选目标/航线，向玩家显示意图；多只幻翼分配空袭顺序，不能全部同时无预警俯冲。
2. **锁定航线**：停止即时追踪，将危险线段/落点固定；保证被攻击方至少有一次有意义的应对机会，而不是只给极短现实时间。
3. **应对窗口**：侧移出路线、靠近有效遮蔽物，或投入行动进行可支持的打断。举盾仅按单次格挡规则处理，不默认抵消整场空袭。
4. **执行空袭**：沿公布路径结算；目标已经躲开则落空，不能最后一刻转向必中。路线发生碰撞要有明确结果。
5. **恢复暴露**：落空或被反制后有追击/反击窗口；不能命中或失败都立刻无成本飞回安全高度。具体是否使用次要行动、恢复 AV 或状态转移另定。

上述预告、实际回合应对、固定路线命中和恢复状态已在第五组实现，具体首版数值与边界见 [第五组行动说明](AERIAL_WIND_ACTIONS.md)。即时俯冲仍作为旧数据包执行能力保留。

### 4.2 骑乘与资源生物的统一规则

- 可控制的骑乘实体用坐骑移动速度计算骑手移动能力；不因此覆盖骑手敏捷、行动顺序或主要/次要行动次数。
- 骑手与坐骑共同移动并校验整体碰撞、上下台阶和摔落。坐骑不另获一次免费移动回合；双人坐骑由控制者提交位移。
- 所有攻击的目标选择优先骑乘者；这不自动等于坐骑免伤，范围伤害、多乘客顺序与骑手死亡/下马要在接口实现时明确。
- 单人可控制生物坐骑的陆地第一组已实现：原版属性预算、整体碰撞/台阶/原版摔伤、同步移动、骑手优先、载体 AV 状态和失效清理。双人/嵌套骑乘、水域/岩浆、主动上下马和更多范围命中策略待实现。当前战斗范围技能只结算参与者骑手，坐骑仍受环境/状态及原版摔伤；详见 [MOUNTED_COMBAT.md](MOUNTED_COMBAT.md)。
- 不参战资源生物不占队列、不阻止战斗结束，场外采集/繁殖等原版玩法不受改变；不得借场外生物绕过战斗中的操作锁定。巨人不适配。

## 5. 范围维护与实现验收

1. 原版机制列用于参考，不是必须逐项复刻的任务清单。用户确认完成的 12 种生物停止追加专属机制，仍修复通用缺陷。
2. 每个新增动作明确主要/次要行动成本、移动预算、AV 冷却和合法目标；具体时长、距离、概率尚未指定的均使用可配置参数，不擅自定为最终平衡值。
3. 验证正常结算、取消/失败、退出清理和多人同场过滤；不能重复消费、重复造成伤害或生成无限增援。
4. Boss 唯一设计来源为 [首领状态机](BOSS_STATE_MACHINES.md)：监守者感知/锁定、末影龙水晶/降落窗口、凋灵印记/危险区。它们尚未实现，按该文最小循环逐步推进。
5. 北极熊保留现状，幻术师暂缓；未点名的扩展不自行扩大本轮范围。

- 官方补充材料：[Java 1.21 更新说明](https://feedback.minecraft.net/hc/en-us/articles/27547857163917-Minecraft-Java-Edition-1-21-Tricky-Trials) 用于试炼生物版本背景；[Meet the Shulker](https://www.minecraft.net/en-us/article/meet-shulker) 用于追踪弹、漂浮及利用/规避漂浮的机制说明。较早文章不用于确定当前复制机制或数值。
