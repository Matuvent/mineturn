# 第五组：幻翼、守卫者与风弹

## 幻翼：预告与恢复

正式 AI 使用 `mineturn:phantom_telegraph`，不再以即时俯冲与普通近战交替作为攻击循环。

1. 选择目标并检查高度优势、视线、完整路线和移动预算。消耗一个主要行动，记录固定的起点、曲线路径和目标当时的位置。
2. 用火花标出路径、粒子标出落点，并向参战玩家发送预告。同场最多一只幻翼处于锁定航线阶段。
3. 至少等待 100 AV，并且被锁定目标必须实际结束一次回合，才允许在幻翼自己的后续回合执行。因此敏捷很高也不能跳过目标的应对机会。
4. 执行再消耗一个主要行动和完整路线的曼哈顿移动距离。使用预告时的路线，不根据目标的新位置转弯。目标离开原位置超过 0.6 格时落空；目标仍需存活、同场敌对、无遮挡且在落点近战范围内。命中调用原版属性近战，不产生普通击退。
5. 执行时起算 150 AV 冷却，并进入恢复：至少 100 AV，且目标再结束一个回合，幻翼才能再次移动或攻击。命中、落空或路径受阻均不会直接免费升空。仍受近身控制时，之后的爬升需要先消耗主要行动撤退。

临时障碍会中止逐步移动，不执行落地攻击；起点被强制位移改变则取消旧航线并进入恢复。目标离场或死亡时取消预告，幻翼死亡、离场或重载时随战斗成员状态清理。恢复时显示粒子，供玩家辨认反击窗口。不制作猫驱退。

旧 `mineturn:phantom_dive` 保留为可调用的即时俯冲执行能力，便于现有数据包兼容；正式幻翼 AI 已不再使用它。

## 守卫者：尖刺窗口

保留已有连续光束、AV 蓄力、遮挡取消与原版伤害。

- 等待且未引导光束时伸出尖刺，符合原版条件的近战触发原版 2 点荆棘伤害。
- 引导光束和移动期间收起尖刺，提供近战反击窗口。
- 光束结束或被遮挡取消后重新伸出。使用原版同步标志驱动尖刺动画，退出战斗恢复原标志。
- 不另加一份反伤，避免与原版受击逻辑重复。

远古守卫者首版采用轮换锁定：有多个敌人时，优先选择不同于上一次光束目标的最近敌人；只有一个目标则继续锁定该目标。每次光束仍单独支付主要行动并完整蓄力，不同时无偿射击所有人。不制作挖掘疲劳、护卫召唤或水域封锁。

## 旋风人与玩家风弹

旋风人注册为地面 AI，射程 16 格，`mineturn:breeze_burst` 每次消耗主要行动，冷却 100 AV；没有合法射击目标时使用已有追击移动。

玩家快捷栏中的原版风弹启用 `mineturn:wind_burst`：消耗一个主要行动和一枚风弹，冷却 100 AV，使用已有远程判定条。未命中仍支付物品、行动和冷却，但不造成伤害或位移。

双方命中共用风爆效果：

- 直接目标受到原版风弹伤害类型的 1 点伤害。
- 目标中心 3 格内、视线无遮挡的同场敌人被向远离施法者的方向推动，默认水平距离 3 格、抬升 0.7 格。
- 位移不扣受击者移动距离，不受近身控制限制；校验扫掠碰撞、已加载区块、世界和战场边界，墙体阻挡时停在安全位置。
- 地面单位移动后按既有落地/摔伤接口结算，没有残留原版击退速度。
- 使用风爆粒子和音效；不运行原版环境爆炸，不破坏方块、不触发红石，不推动友军或战场外目标。

此批未制作旋风人原版跳跃选位、投射物偏转、玩家对地风跳或场外风弹行为改动；原版场外使用保持原样。水中强制位移仍受现有空间路径的液体边界限制。

## 数据包与验证入口

资源路径均在 `data/mineturn/`，生物映射优先级 `-100`；可以使用外部数据包或附属模组覆盖对应 JSON 和 mcfunction。

- 幻翼：`mineturn/actions/phantom_telegraph.json`、`function/ai/phantom/`。
- 远古守卫者：`mineturn/mobs/elder_guardian.json`、`function/ai/elder_guardian/turn.mcfunction`。
- 风弹：`mineturn/actions/wind_burst.json`、`breeze_burst.json`，参数 `push_distance` 范围 0–8；`mineturn/items/wind_charge.json`。
- 函数 AI 新增目标策略 `alternate_enemy`，按上一光束目标选择其他敌人；没有其他目标时仍可选择原目标。

服务器测试覆盖预告应对、固定路线躲避、命中与受阻、恢复及撤退、尖刺开合/原版反伤、远古守卫者轮换、风弹命中/未命中的支付、墙体阻挡、场外保护和旋风人位移。客户端粒子可读性、尖刺动画与风弹手感仍需实测。

验证结果：完整 156 项服务器 GameTest 全部通过，`runGameTestServer build --offline` 构建成功；日志 `build/group-five-tests.log`。
