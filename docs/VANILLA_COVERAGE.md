### 关于"物品 1333"

这个数字**不能**当作"覆盖了 1333 件物品"。原版兜底（`catalog/vanilla.json`）会遍历整个物品注册表，
把**所有**尚未映射的原版物品登记为 `enabled=false`、无动作——目的是让"注册表完整"，
使外部数据包能确定地覆盖任何物品。

**真正的可用面是 86 件**：武器、工具、食物、药水、弓弩、三叉戟等。

> 兜底连 `minecraft:air` 也一并登记（无害，空气不会被手持）。测试会记录这条信息，但不视为缺陷。

## 2. 四个状态词（不要混用）

| 状态 | 判据 |
| --- | --- |
| **已注册** | 存在内置 JSON 定义 |
| **可用** | 有动作且未被禁用，且参与策略允许入战 |
| **禁用** | `enabled:false`，或无登记，或参与策略为 `never` |
| **待实测** | 服务端已验证，但画面/手感/联机需真机确认 |

**已注册 ≠ 机制完整 ≠ 可用。** 例如某生物已登记基础追击近战，但它的变种转换、专属战术仍可能未适配。

## 3. 资源生物不参战（用户明确要求）

`data/mineturn/tags/entity_type/non_combatants.json` 列出 **38 种**资源/中立生物（悦灵、蝙蝠、骆驼、猫、
鸡、牛、海豚、狐狸、马、猪、羊、村民、流浪商人等）。

判定逻辑（`BattleParticipation.allowed`）：

| `participation` | 结果 |
| --- | --- |
| `never` | **永不入战** |
| `auto` | **仅当不在资源标签内**才入战（资源生物靠这条被排除） |
| `hostile` / `neutral` | 入战，**忽略**资源标签 |

**测试硬性保证**：任何列在资源标签内的生物，若其 `participation` 不是 `auto`/`never`，测试失败。
这条把"不得重新让资源生物参战"从文档约定变成了**可执行的约束**。

## 4. 已实现的特殊行为（按实现批次）

以下为**实现记录**。旧的进度数字（登记 36/37/39/40、测试 142–171、协议 11/12）已删除——
它们互相矛盾且无法核对，现统一由 §1 的实测矩阵取代。

### 第四、五组：末地、水域与空中

- **潜影贝**：开闭壳、独立可攻击的追踪弹（模组实体，不计入原版 40）
- **末影人**：次要行动瞬移；原版阵营
- **幻翼**：固定航线预告、真实回合应对与恢复；`mineturn:phantom_dive` 俯冲（8 格、150 AV 冷却，沿下倾曲线飞向目标侧面）；高度不足时拉升 3 格；被近身控制时先撤退
- **守卫者 / 远古守卫者**：严格水域移动 + `mineturn:guardian_beam`；400 AV 冷却，原版蓄力 80/60 tick → 400/300 AV；结算时重检 16 格射程与视线；**按用户要求不制作挖掘疲劳光环**
- **旋风人**：与玩家风弹共用原版伤害类型和强制位移
- **烈焰人**：充能连射（0/10/20 AV 命中点，200 AV 冷却）
- **恶魂**：游荡火球
- **末影螨**：短距离近战；寿命与来源关联仇恨未适配
- **蠹虫**：`mineturn:silverfish_summon`（半径 4、上限 3、200 AV）；只用已加载的真实虫蚀方块；要求 `mobGriefing=true`；尊重生物破坏与实体生成取消

### 第三组：灾厄

- **掠夺者 / 猪灵**：主副手持弩时可射击（16 格、基础 100 AV，快速装填缩短）；弹药由生物供应；命中与否都扣一次耐久
- **卫道士**：破盾（盾冷却 100 AV）、敏捷 160
- **唤魔者**：召唤恼鬼（同场至多 3 只）、双圈/直线尖牙
- **女巫**：低血优先原版治疗药水，否则概率缓慢/随机伤害/中毒
- **劫掠兽**：盾挡沿用原版 50% 眩晕概率，眩晕 200 AV → 吼叫 100 AV，第 50 AV 造成 6 点范围伤害

### 第二组：自爆与分裂

- **苦力怕**：`mineturn:creeper_explode`，2 格内消耗主要行动直接爆炸；读原版 `ExplosionRadius`（上限 16），高压翻倍；**不伤友军、不破坏地形、不点火、不击退**；事件取消时无伤害但行动仍消耗、自身仍移除
- **史莱姆 / 岩浆怪**：大个体死亡立即完成原版分裂，省去 20 tick 尸体等待；子体继承阵营、按完整行动间隔入队；尊重分裂取消与实体生成取消

### 第一组：水域与中立

- **溺尸**：陆追水时尝试三维水路；跨水陆用同一条已验证路线；持三叉戟优先合法投掷（`mineturn:drowned_trident`，16 格、100 AV，命中调原版 `ThrownTrident.onHitEntity`，基础 8 点，**不消耗也不损坏手持武器**）
- **僵尸猪灵**：不因附近有战斗自动入场；实际伤害激怒受击者并通知 16 格内同类（不递归传播）；愤怒用原版目标 UUID 与随机时长，每 5 AV 推进一 tick

### 攀爬、飞行与分裂系

- **蜘蛛 / 洞穴蜘蛛**：`movement_mode: "climbing"`，每个采样点需地面或邻近墙面支撑；跳扑消耗主要行动、200 AV 冷却、弧线最高额外抬升 0.75 格
- **恼鬼**：`phasing` 逐步穿墙追击；原版有限寿命按每 5 AV 扣 1 tick，到期后每 100 AV 造成 1 点原版饥饿伤害

### 远程与物种近战

- **骷髅 / 流浪者 / 沼骸**：独立 mcfunction AI；主线持弓且目标无遮挡、16 格内、冷却就绪时射击；`mineturn:skeleton_arrow` 保留难度随机伤害、力量/火矢附魔与流浪者 600 tick 缓慢、沼骸 100 tick 中毒
- **凋灵骷髅**：主副手持弓时调用骷髅远程 AI，命中附加原版 5 秒燃烧；失去弓后恢复 `species_melee` 近战与凋零
- **尸壳**：改用 `mineturn:species_melee`，空手且命中成功才施加饥饿，时长 `140 × 当地有效难度` tick
- **铁傀儡 / 疣猪兽 / 劫掠兽**：基础地面追击 + 特殊近战；铁傀儡可协助附近玩家，但正针对玩家时不自动协战
- **狼 / 北极熊**：基础追击 + `mineturn:mob_melee`；未坐下的驯服狼可随主人协战

`mineturn:species_melee` **只接受**蜘蛛系、尸壳、凋灵骷髅、铁傀儡、疣猪兽、僵尸疣猪兽、劫掠兽——
它不是任意模组生物的原版攻击代理。

### 支援与召唤

- **雪傀儡 / 蜜蜂**：支援与有限刺击（`mineturn:bee_sting`）
- **美西螈**：协战、AV 装死/苏醒/干涸、有条件击杀治疗
- **铁锭修复 / 狼铠材料修复**：见 [美西螈与修复](AXOLOTL_AND_REPAIRS.md)

### 坐骑

单人可控坐骑的陆地战斗；**不新增坐骑 AI 登记**，仍为 40 种。见[骑乘战斗](MOUNTED_COMBAT.md)。

## 5. 原版物品兜底

`data/mineturn/mineturn/catalog/vanilla.json` 开启兜底（`{"enabled":true}`）。

| 规则 | 行为 |
| --- | --- |
| 显式物品 JSON 与物品组件 | **优先**于兜底 |
| 剑 / 挖掘工具 / 重锤 | 开放 `mineturn:melee`，读原版攻击属性与附魔 |
| 普通食物 | 开放 `mineturn:eat`，读 FOOD 组件（不在 JSON 里固定恢复量） |
| 蜂蜜 / 谜之炖菜 / 蘑菇煲 / 兔肉煲 / 甜菜汤 | `mineturn:native_food`，调原版进食逻辑，保留效果组件与容器返还；该行动 `consume=0`，避免重复扣除 |
| 其它原版物品 | **登记为 `enabled:false`**，战斗中不可用 |
| 关闭整个兜底 | 同路径覆盖为 `{"enabled":false}` |

弓、弩、药水等已有**显式映射**，优先于兜底。

> **重要**：`{"enabled":false}` **只写这一句**即可关闭（早期实现要求同时写 `actions`，会导致解析失败，已修）。
> 详见 [数据包覆盖语义](DATAPACK_OVERRIDE_SEMANTICS.md)。

## 6. 数据包可覆盖

上述内置 JSON、mcfunction、AI 函数与镜头配置**均可被外部数据包/资源包覆盖**。
覆盖、禁用与可选引用的确切语义见 [数据包覆盖语义](DATAPACK_OVERRIDE_SEMANTICS.md)。

示例中的较高优先级规则会覆盖内置注册；已知两处：

- 旧空间示例把**普通守卫者**覆盖为游泳近战——需移除该覆盖才能使用内置光束
- 旧空间示例把**恼鬼**覆盖为普通 flying——需移除该覆盖才能使用新的 phasing 行为
