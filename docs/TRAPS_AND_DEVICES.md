# 进入陷阱与可攻击机关

沿用 CombatFields 危险区域接口，新增 trigger、charges、core_health。必须同时更新客户端和服务端（协议 19），新增 mineturn:field_core 实体及“机关 · 不行动”全员列表提示。

## 使用示例

构建 `./gradlew.bat trapActionExamplePack`，安装 build/examples/mineturn-trap-actions-example.zip 到存档 datapacks 后 /reload。

- 进战前穿铁靴：右侧“布置陷阱”，消耗一次主要行动，在自己世界坐标 +X 两格处放半径 1、高 2 格的一次性陷阱。敌人进入时造成 4 基础伤害，消耗后移除；150 AV 到期，150 AV 动作冷却。
- 进战前戴钻石头盔：右侧“部署机关”，消耗一次主要行动，创建相同位置和范围的周期领域，附带 8 血量机关核心，每 25 AV 造成 4 基础伤害，150 AV 到期优先删除。核心用铜块模型表示，不是放置方块。敌人可以攻击核心来提前解除领域。

两个示例不消耗经验，不扣装备耐久；可在 grants JSON 中配置资源费用。示例不默认启用，现有普通危险区域参数不变。

## 数据包参数

在 hazard_field 动作的 parameters 中配置：

```json
"trigger": "enter",
"charges": 1,
"core_health": 8
```

trigger 为 periodic（默认）或 enter。进入陷阱必须有 1–16 次 charges，默认为 1；周期区域 charges 必须为 0（默认）。core_health 为 0（默认无核心）或不超过 1000 的正数，两种触发模式都能搭配核心。半径、高度、周期和寿命仍遵守原有范围；进入陷阱不使用周期伤害，但 interval_av 的旧校验仍保留，lifetime_av 必须大于它。

Java 可使用完整构造器 `new CombatFields.Request(center, radius, height, intervalAv, lifetimeAv, onEnter, charges, coreHealth)`。旧五参数构造器仍表示无核心的周期区域。

## 进入判定

- 以目标 XZ 位置进入圆形范围、实体包围盒与区域高度相交判断；只对无遮挡的同场敌人触发。
- 创建时已经站在范围内不会立刻中招，必须离开再进入；站在里面等待不会重复触发。
- 每次由外到内消耗一次次数。先扣次数再执行效果，最后一次先删除陷阱，避免重复提交或回调重入获得额外触发。
- 正常逐步移动、备用同步移动和技能位移检查实际经过的路线，即使两端都在范围外也能触发。传送只检查落点，不检查中间经过的空间。
- 战斗位置校正/直接落点安置采用落点进入规则；当前不额外模拟原版实时自由移动。外部模组应使用 MineTurn 移动/位移/传送接口，不直接改坐标绕过这些入口。
- 不消耗被触发者额外的行动或普通移动预算，伤害和其他效果使用原动作回调。

## 核心规则

核心会加入同场目标列表，但不会获得独立回合，不提供周身控制、不主动攻击。它跟随施法者敌我关系，可被现有近战、远程和范围伤害攻击；没有物品和经验掉落，不保存到世界。

核心需要方块中心 XZ 位置、无方块/实体占用，受战斗 32 名成员上限限制；创建事件取消或状态变化时清理候选实体。核心不能被技能位移或传送，区域位置固定。核心死亡、施法者离场、主动取消、次数耗尽、区域到期或战斗结束都会同时清理核心和区域。

核心借用可受伤实体实现目标选择，暂不提供机关编辑面板、材质定制、方块放置/破坏、红石交互或持久化。客户端模型、点击选择及联机表现需要实测。
