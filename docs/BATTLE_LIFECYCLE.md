# 战斗退出与服务器生命周期

## 当前规则

- 玩家注销：立即退出所在战斗，清理其临时召唤物、陷阱和机关，以及以其为施法者或目标的待结算技能。其他参与者仍有敌对关系时继续战斗。
- 玩家跨维度：收到原版跨维度完成事件后立即执行同一退战流程，不等待下一次战斗 tick。
- 正常停服：在 ServerStoppingEvent（玩家与世界最终保存之前）结束该服务器全部战斗；收尾期间不再由伤害发起新战斗。
- 正常离场保留药水效果和燃烧的剩余时间，解除战斗时钟锁；盾牌、末影珍珠、紫颂果、风弹按剩余 AV 换算回原版冷却。不会因退出而退款已经支付的行动费用。
- 忠诚三叉戟沿用现有回收规则：只回收实际存在、同维度且可访问的掉落实体，不凭空补发。跨维度后原维度的实体不自动复制进背包。

## 边界

当前采用“离线即退战”，不保存战斗时间轴，不提供离线身体或重连续战。原版物品冷却在在线离战后恢复倒计时；这不代表新增了原版冷却的跨重登持久化。进程强杀、断电或崩溃不保证触发正常停服事件。临时召唤物另有磁盘重载孤儿清理，机关核心不存档。

自动化验证覆盖注销/跨维度事件退战、正常停服清理、召唤物与核心删除、待结算技能取消、剩余冷却交接及重复关闭幂等性。跨维度客户端画面、真实断线重连和专用服务器重启仍需游戏内联机实测。
