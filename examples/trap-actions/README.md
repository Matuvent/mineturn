# 进入陷阱与机关示例

需要新版 MineTurn（客户端和服务端都更新，协议 19）。安装数据包并 /reload，进战前穿铁靴以获得“布置陷阱”，戴钻石头盔以获得“部署机关”。

两者各花一次主要行动，冷却 150 AV，不额外消耗资源。放在自身世界坐标 +X 两格，半径 1、高 2，寿命 150 AV。陷阱进入触发一次 4 基础伤害；机关每 25 AV 造成 4 基础伤害，附带 8 血可攻击铜块外观核心，摧毁后领域消失。只针对敌人。

创建在敌人脚下的进入陷阱不立即触发，需敌人离开再进入；站着等待不触发。示例不会默认启用。完整参数与限制见 docs/TRAPS_AND_DEVICES.md。
