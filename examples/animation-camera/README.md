# 动作技能镜头示例（资源包）

把 `examples/animation-camera/` 打包成 zip（或直接把目录放进 `resourcepacks/`），
在客户端启用即可**覆盖**模组自带的技能机位配置。

**这是资源包，不是数据包**：只包含 `assets/`，没有 `data/`。
放在客户端 `resourcepacks/` 目录；放在服务端**不会**生效。

## 它做了什么

覆盖 `assets/mineturn/mineturn/animation_camera.json`（与模组自带同路径），
提供近战 / 进食 / 饮用 / 射击四种基础预设，数值**刻意比默认值更大**，便于一眼确认是否生效：

| 动画 | 默认 `side` | 本示例 `side` |
| --- | --- | --- |
| `melee` | 0.95 | **1.25** |
| `ranged` | 0.70 | **0.95** |
| `eat` | 0.60 | **0.80** |
| `drink` | 0.65 | **0.85** |
| `generic` | 0.85 | 1.10 |

同时把回落时长 `blend_out_ms` 从默认 `80` 改成 `120`，便于对比"回落快慢"这一项。

> **切入是硬切**（瞬间跳到技能机位）。`blend_out_ms` 只控制结束回落到自由镜头的时长，
> 设为 `0` 则瞬时回弹。

## 怎么确认生效

1. 启用本资源包后启动客户端；
2. 进战斗，用近战打一下；
3. 镜头应比默认**明显更靠右、更远**（约 2.9 格 vs 默认约 2.5 格）。

也可以对比：不启用时更近，启用后变远。

> 若数值改坏，模组会记录错误并回落内置默认，不会崩溃。
> 静态检查：`python tools/validate_examples.py`。
